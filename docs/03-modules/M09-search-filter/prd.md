# M09 Search & Filter — Product Requirements

## Search and filter

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-61 | The system shall allow a user to search all tasks, including completed ones, by a keyword in the title or description. | Finds items quickly as the list grows. | High |
| FR-62 | The system shall display each search result with its project, due date, and completion status. | Helps users identify the right task. | Low |
| FR-63 | The system shall open a task’s details when the user selects it from the search results. | Lets users act on what they find. | Low |
| FR-64 | The system shall allow a user to filter tasks by project, priority, completion status, and due date. | Narrows long lists to what is relevant. | Low |
