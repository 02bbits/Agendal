# M05 Recurrence — Product Requirements

## Recurrence

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-39 | The system shall allow a user to set a task to repeat daily, weekly, monthly, or yearly, through a message or manually. | Avoids re-entering routine tasks. | High |
| FR-40 | The system shall allow a user to set an end date for a repeating task. | Routines such as a semester have an end. | Low |
| FR-41 | When a repeating task is marked complete, the system shall create its next occurrence. | Keeps the routine going without user effort. | High |
| FR-42 | When a user edits or deletes a repeating task, the system shall let them apply the change to that occurrence only or to all future occurrences. | A single occurrence may differ or be cancelled. | Low |
