# M03 Task Management — Product Requirements

## Tasks

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-23 | The system shall allow a user to create a task manually by entering only a title. | Quick capture when the assistant is not wanted or unavailable. | High |
| FR-24 | The system shall allow a user to edit a task’s title, description, priority, due date, scheduled time, reminder, and project. | Task details change over time. | High |
| FR-25 | The system shall offer three task priority levels: High, Medium, and Low. | Helps users decide what to do first. | High |
| FR-26 | The system shall allow a user to delete a task after confirming the deletion. | Removes unneeded tasks without accidental loss. | High |
| FR-27 | The system shall allow a user to mark a task as complete. | Tracks progress. | High |
| FR-28 | The system shall allow a user to reopen a completed task. | Corrects tasks completed by mistake. | Low |
| FR-29 | The system shall allow a user to schedule a task by assigning a date, start time, and end time. | Reserves time to work on the task. | High |
| FR-30 | The system shall reject a scheduled time whose end time is not later than its start time. | Prevents invalid entries. | High |
| FR-31 | The system shall allow a user to remove a task’s scheduled time without deleting the task. | Plans change while the task remains. | Low |
| FR-32 | The system shall label a task as overdue when its due date has passed and it is not complete. | Draws attention to missed deadlines. | High |
