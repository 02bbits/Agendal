# M04 Projects — Product Requirements

## Projects

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-33 | The system shall allow a user to create a project by entering a name, either manually or through the assistant. | Groups related tasks under one goal. | High |
| FR-34 | The system shall allow a user to rename a project. | Project names change as goals evolve. | Low |
| FR-35 | The system shall allow a user to delete a project and choose whether its tasks are deleted or moved to No project. | Removes finished projects without losing tasks by accident. | High |
| FR-36 | The system shall group tasks that have no project under No project. | Ensures every task has a place. | Medium |
| FR-37 | The system shall display, for each project, the number of completed tasks out of its total tasks. | Shows project progress. | Low |
| FR-38 | The system shall allow a user to assign a colour to a project. | Makes projects recognisable across views. | Medium |
