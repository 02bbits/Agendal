# M01 Identity & Access — Product Requirements

## Accounts

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-01 | The system shall allow a user to register with an email address and a password. | Keeps each user’s data separate and private. | High |
| FR-02 | The system shall allow a registered user to log in with their email address and password. | Restricts data access to its owner. | High |
| FR-03 | The system shall allow a logged-in user to log out. | Protects data on shared devices. | High |
| FR-04 | The system shall allow a user to reset a forgotten password through a link sent to their registered email address. | Lets users regain access without support. | High |
| FR-05 | The system shall show a user’s tasks, projects, and assistant conversation on any device where they log in. | Users switch between phone and computer. | High |
| FR-06 | The system shall allow a user to delete their account and all data stored in it. | Gives users control of their personal data. | Low |
