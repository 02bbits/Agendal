# M10 PWA & Offline — Product Requirements

## App access

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-65 | The system shall allow a user to install the app on a phone or computer from the browser. | Quick access without an app store. | High |
| FR-66 | The system shall display previously loaded tasks when the device has no internet connection. | Users check their tasks while offline. | Low |
| FR-67 | The system shall save manual changes made offline to the user’s account when the connection returns, and shall show that the assistant is unavailable while offline. | Prevents loss of offline work and sets clear expectations. | |
