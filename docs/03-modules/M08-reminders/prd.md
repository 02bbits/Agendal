# M08 Reminders — Product Requirements

## Reminders

| ID | Requirement | Rationale | Priority |
|---|---|---|---|
| FR-56 | The system shall allow a user to set a task reminder at a chosen date and time, or 5, 15, or 30 minutes, 1 hour, or 1 day before its scheduled start. | Gives users time to prepare. | High |
| FR-57 | The system shall send a push notification to the user’s device at the reminder time. | Reaches users when the app is closed. | High |
| FR-58 | The system shall ask for the user’s permission before sending notifications. | Respects user choice. | High |
| FR-59 | The system shall allow a user to remove a reminder from a task. | Reminders may no longer be needed. | Low |
| FR-60 | The system shall open the related task when the user taps a notification. | Lets users act on the reminder at once. | Low |
