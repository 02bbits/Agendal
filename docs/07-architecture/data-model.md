# Data Model

Physical model for the [domain records](../02-domain/domain.md). The database is PostgreSQL ([Q14](../08-project/open-questions.md#q14)), with the `pg_trgm` and `unaccent` extensions. Every table except `users` has `user_id`, and every query is scoped to it ([NF-9](../05-quality/nfr.md#nf-9)).

| Table | Columns | Constraints / notes |
|---|---|---|
| `users` | id, email, display_name, password (hash), timezone, remember_device, theme (system / light / dark), week_start (mon / sun), time_format (24h / 12h), install_prompt_shown, created_at | email unique, stored lower case. Argon2id hash, never logged ([NF-10](../05-quality/nfr.md#nf-10)). `timezone` is an IANA name ([ADR-006](decisions/ADR-006-time-zones.md)) |
| `projects` | id, user_id, name, colour, created_at, change_seq, deleted_at? | colour ∈ the 8 project tokens ([PJ-1](../03-modules/PJ-projects.md#pj-1)). UNIQUE (user_id, lower(name)) where not deleted. ≤ 50 per user ([NF-14](../05-quality/nfr.md#nf-14)) |
| `tasks` | id, user_id, project_id?, title, due_date?, start_time?, end_time?, priority?, reminder (default `none`), repeat, notes?, done, done_at?, created_by, source_note_id?, created_at, updated_at, field_updated_at (jsonb), remind_at?, repeat_anchor?, previous_occurrence_id?, change_seq, deleted_at? | CHECK end_time > start_time ([TK-3](../03-modules/TK-tasks.md#tk-3)). priority ∈ {low, medium, high}. repeat ∈ {never, daily, weekly, monthly, yearly}. created_by ∈ {user, assistant}. `field_updated_at` holds per-field timestamps for LWW ([ADR-004](decisions/ADR-004-offline-sync-field-level-lww.md)). Dates and times are floating local values. `remind_at` is UTC ([ADR-006](decisions/ADR-006-time-zones.md)). title ≤ 200, notes ≤ 5,000 ([NF-14](../05-quality/nfr.md#nf-14)). `id` is a client-generated UUID v7. `previous_occurrence_id` is UNIQUE, so one completion makes one next occurrence ([TK](../03-modules/TK-tasks.md#8-data-validation-and-authorization)) |
| `notes` | id, user_id, client_id, text, name?, source_file_name?, status, plan (jsonb), applied (jsonb), undo_log (jsonb)?, engine, prompt_version?, written_at, written_tz, created_at, processed_at?, edited_at?, change_seq | UNIQUE (user_id, client_id) for idempotent replay ([ADR-003](decisions/ADR-003-offline-note-queue-and-idempotency.md)). status ∈ {pending, new, done, confirm, followup, kept, undone}. engine ∈ {rules, rules_llm, rules_fallback} ([ADR-008](decisions/ADR-008-llm-fallback.md)). text ≤ 5,000 ([NF-14](../05-quality/nfr.md#nf-14)). `undo_log` holds the reverse log for the 10 s redo, and `edited_at` is set by Edit note ([RV](../03-modules/RV-review-control.md#8-data-validation-and-authorization)) |
| `password_reset_tokens` | email, token (hashed), created_at | Laravel's built-in reset table: hashed, single use, expires after 60 min ([AA-4](../03-modules/AA-account-access.md#aa-4)) |
| `push_subscriptions` | user_id, endpoint, keys | [TK-6](../03-modules/TK-tasks.md#tk-6) |
| `reminder_deliveries` | task_id, remind_at, sent_at | UNIQUE (task_id, remind_at), so each reminder is sent once |
| `audit_events` | id, user_id?, event, ip, user_agent, created_at | Kept 90 days ([NF-20](../05-quality/nfr.md#nf-20)). No secrets |

`applied` is a list of `{kind, task_id, before, label}` ([note model](../02-domain/domain.md#change)). Deletes set `deleted_at` (tombstones for sync, [ADR-005](decisions/ADR-005-sync-protocol.md)). Rows are purged after 30 days, unless an undoable note still references them ([ADR-002](decisions/ADR-002-undo-change-log.md)).

Indexes (all lead with `user_id`, [scalability](../05-quality/scalability.md)): `(user_id, change_seq)` on tasks, projects and notes for sync, `tasks (remind_at)` where not sent, `tasks (user_id, due_date)`, `tasks (user_id, done)`, and a trigram GIN index on `unaccent(title || ' ' || notes)` for accent-insensitive search ([LV-3](../03-modules/LV-lists-search.md#lv-3)) and command matching ([NU-3](../03-modules/NU-note-understanding.md#nu-3)). `notes (user_id, written_at desc, id)` for the Notes tab ([RV-4](../03-modules/RV-review-control.md#rv-4)).
