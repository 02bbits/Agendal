# Usability

The visual and voice spec is the [theme guide](../01-product/theme-guide.md).

| ID | Requirement |
|---|---|
| NF-1 | Meets WCAG 2.2 AA: text contrast ≥ 4.5:1 and control borders ≥ 3:1 in both themes; colour never carries meaning alone |
| NF-2 | Touch targets ≥ 44 × 44px; every icon-only button has an accessible name; visible 2px focus ring on every control; full keyboard use; respects reduced-motion |
| NF-3 | Works with VoiceOver and TalkBack; status changes ("Listening…", "Reading file…", toasts) are announced |
| NF-8 | Fluid from 320px to 480px wide (360px reference), centred column up to 600px, `100dvh` height, safe-area insets respected; no native status bar or keyboard drawn |
| NF-12 | Follows the theme guide's voice: sentence case, 24-hour times, short dates, no emoji |
