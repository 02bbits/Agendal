# WF-03 — Resolve an Unclear Note

**Trigger:** A plan has nothing actionable (NU-4). For example, *"idea: dark mode for the portfolio site"*.

## Main flow

1. The note's status becomes `followup`.
2. The result screen says "I couldn't find a task in this note." and offers **Keep as note** or **Make it a task** (RV-3).
3. **Keep as note:** the status becomes `kept`. The note is named from its first words (NU-6), e.g. "Ideas for the portfolio site".
4. **Make it a task:** one task is created from the note's text, and the status becomes `done`. It can be undone like any note.
