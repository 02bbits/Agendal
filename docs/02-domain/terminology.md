# Terminology

Domain terms, used the same way in requirements, UI copy, and code. For acronyms and technical terms, see the [glossary](../08-project/glossary.md).

| Term | Definition |
|---|---|
| Note | Free text the student writes, dictates or attaches. It is turned into tasks once and kept in the Notes tab |
| Item | One piece of a note after splitting on new lines, commas, semicolons, full stops and "then" (NU-1) |
| Plan | What the assistant intends to do with a note: create, change, delete, skip |
| Command | An item that acts on an existing task: complete, reschedule or delete (NU-3) |
| Skipped text | Items that make no task: ideas, FYIs, filler (NU-4) |
| Change | One applied create, change or delete, with enough data to undo it |
| Result screen | Lists every change from a note with CREATED / CHANGED / DELETED badges (RV-1) |
| Undo all | Reverses every change from one note. The note is kept and marked Undone (RV-2) |
| Check this first | The confirmation shown before a risky plan: any delete, or more than 5 changes (NU-5) |
| Follow-up | The one question for a note with nothing actionable: Keep as note, or Make it a task (RV-3) |
| Note name | A name generated from the plan, e.g. "This week" or "SQL Course to-dos" (NU-6) |
| Pending note | A note saved offline, shown as "Waiting for connection" (NC-6) |
| Due date | When the task must be done |
| Schedule | When the student will work on it: a start time and an end time |
| Overdue | Not done, and the due date has passed. Shown in red with a count in Inbox (LV-1) |
| Today | Tasks due or scheduled today |
| No project | Tasks without a project. It is not a record |
| Created by the assistant | Label on tasks made from a note (NU-7) |
