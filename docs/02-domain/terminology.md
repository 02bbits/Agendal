# Terminology

Domain terms, used the same way in requirements, UI copy, and code. For acronyms and technical terms, see the [glossary](../08-project/glossary.md).

| Term | Definition |
|---|---|
| Task | An actionable item the user wants to complete. Only a title is required. |
| Due date | When the task must be finished (a deadline). |
| Scheduled time | When the user plans to **work** on the task: a date plus start and end time. Independent of the due date. |
| Priority | High, Medium, or Low. |
| Overdue | A derived label: the due date has passed and the task is not complete. It is not a stored state. |
| Today's tasks | Tasks due **or** scheduled today. |
| Upcoming | Tasks due or scheduled after today. |
| No project | The implicit group for tasks without a project. It is not a real project and cannot be renamed or deleted. |
| Repeating task / series | A task with a repeat rule. Each instance is an **occurrence**. |
| Reminder | A notification time, either absolute or relative to the scheduled start (5/15/30 min, 1 h, 1 day before). |
| Nudge | An automatic notice when a task becomes overdue, or is due within 24 h with no scheduled time. |
| Morning summary | A daily notification at a user-chosen time listing today's and overdue tasks. |
| Encouragement | A short message shown when a task is completed. |
| Assistant reply | The assistant's response to one user message. |
| Change set | All task changes made by one assistant reply. It is the unit of undo. |
| Summary card | The UI listing of a change set (created/changed/deleted tasks). |
| Free slot | A time window with no scheduled task, suggested for unscheduled work. |
